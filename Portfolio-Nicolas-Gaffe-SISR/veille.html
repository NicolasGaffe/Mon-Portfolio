Deux points à retenir.

27 octobre 2026 · Note de référence

GLPI : n’exposer que le répertoire web prévu.

Constat. La configuration Apache de référence pour GLPI 10.0.7 ou ultérieure expose le sous-répertoire public, avec les règles de réécriture adaptées.

Application au laboratoire. Vérifier le VirtualHost, le chemin d’installation et l’URL avant de déployer ; conserver les fichiers sensibles hors de l’espace servi au navigateur.

Suite à documenter. Version installée, configuration anonymisée et test des chemins accessibles.

27 octobre 2026 · Note de référence

Agent GLPI : distinguer chemin HTTP et confiance TLS.

Constat. Une réponse 404 signifie que la ressource demandée n’a pas été trouvée. L’URL attendue par l’agent varie selon la version et les extensions GLPI utilisées.

Application au laboratoire. Contrôler d’abord l’URL configurée et les journaux. Pour une erreur TLS, vérifier le certificat et sa chaîne de confiance, en conservant la validation des certificats.

Suite à documenter. Symptôme observé, diagnostic, correction et résultat du nouvel inventaire.
