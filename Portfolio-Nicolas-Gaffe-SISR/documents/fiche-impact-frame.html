01. Contexte & objectif

Donner accès à une réalisation web et à son code source depuis le portfolio.

02. Environnement documenté

Dépôt GitHub Impact-Frame fourni dans le portfolio initial. La pile technique et le périmètre personnel ne sont pas détaillés dans les documents joints.

03. Démarche décrite

  1. Référencer le dépôt du projet.
  2. Présenter la maquette parmi les réalisations complémentaires.

04. Plan de vérification

  • Compléter la fiche avec le rôle, la pile technique et des captures représentatives.
  • Ajouter les vérifications d’affichage et les éventuels tests fonctionnels.

Ces contrôles sont à joindre au dossier avec leurs résultats ; ils ne constituent pas un compte rendu de tests exécutés.

05. Livrables & résultats

Lien vers le dépôt fourni ; documentation technique locale absente.

Contribution personnelle : les documents décrivent une démarche ; le rôle exact, les dates et le périmètre individuel restent à préciser avant l’oral.
